## 4. 首次启动问题

首次执行在 ROS 节点启动前退出：

```text
/opt/ros/foxy/setup.bash: line 8:
AMENT_TRACE_SETUP_FILES: unbound variable
```

调查确认：

- `/opt/ros/foxy/setup.bash` 第 8 行直接读取该可选变量；
- 启动器顶部启用了 `set -u`；
- 在相同环境下可稳定复现；
- 关闭 nounset 后可正常加载环境。

处理：

1. 新增失败回归测试；
2. 在加载 Unitree、Livox 和 FAST-LIO2 环境期间执行 `set +u`；
3. 环境加载后恢复 `set -u`；
4. 本地 30 项测试通过；
5. Jetson 启动器 7 项测试和 Bash 语法检查通过；
6. 再次运行输入探针成功。

## 5. FAST-LIO2 静止冒烟测试

命令：

```bash
timeout --signal=INT --kill-after=5 35 \
  bash scripts/go2_l2/run_fastlio2_l2.sh --skip-probe \
  > /tmp/go2_l2_fastlio2.log 2>&1
```

关键日志：

```text
p_pre->lidar_type 2
Node init finished.
IMU Initial Done
Initialize the map kdtree
```

初始化阶段出现一次：

```text
No point, skip this scan!
```

此后持续正常发布，因此没有按持续丢点处理。

输出监测窗口为 15 秒：

| 输出 | 消息数 | 频率 |
|---|---:|---:|
| `/Odometry` | 231 | 15.3949 Hz |
| `/cloud_registered` | 231 | 15.3944 Hz |
| `/cloud_registered_body` | 231 | 15.3943 Hz |

坐标系：

```text
header.frame_id = camera_init
child_frame_id  = body
```

静止漂移：

| 指标 | 值 |
|---|---:|
| 平移漂移 | 0.0117266 m |
| 偏航漂移 | 0.0193832 rad |
| 偏航漂移 | 约 1.11° |

限时进程退出码为 `124`，日志中的子进程 `exit code -2` 来自测试结束时的
SIGINT。测试后确认没有遗留 `fastlio_mapping` 进程。

## 7. 结论

已证明：

- 机载雷达数据特征属于 Unitree L2；
- L2 原始点云和内置 IMU 可以直接被当前 ROS 2 FAST-LIO2 消费；
- 第一版无需修改 FAST-LIO2 第三方预处理源码；
- 静止初始化和持续输出正常；
- 静止漂移处于可继续动态验证的水平。

尚不能宣称：

- 动态里程计已经通过；
- PCD 地图质量已经通过；
- Nav2 已切换到 L2；
- 深度相机已经接入。

以上项目需要后续单独验证，动态阶段必须重新取得运动授权。
