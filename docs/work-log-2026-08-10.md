## 第二层：技术明细

### 1. 导航 Pipeline

```text
MID360S -> Livox Driver -> FAST-LIO2
  -> /Odometry、/cloud_registered、/cloud_registered_body
  -> odom_tf_bridge -> /odom、odom -> base_link
  -> ICP localization + MID360.pcd -> map -> odom
  -> go2_pc2scan -> /scan
  -> Nav2 -> /cmd_vel
```

Nav2 启动由 readiness 条件驱动，不依赖固定长 sleep。Nav2 内只保留一个 `map_server`，DWB 为默认控制器，RPP 作为可选 profile；waypoint follower 和行为树继续保留。

### 2. 控制与 Web 安全

正式运动链路为：

```text
Nav2 /cmd_vel 或 Web /go2/manual_cmd_vel
  -> go2-motion-sender.service（Jetson，20 Hz）
  -> UDP 192.168.123.5:15001 -> 192.168.123.18:15000
  -> go2_cmd_gateway
  -> Unitree SportClient
  -> Go2 192.168.123.161
```

协议覆盖 session、sequence、CRC、Arm 令牌、限速、ACK、双端 watchdog、站立、趴下和锁存急停。Web 后端统一认证、CSRF、单操作者租约、状态新鲜度和 `{ok, code, message, data}` 响应；rosbridge 只读，不能绕过后端发布运动指令。
